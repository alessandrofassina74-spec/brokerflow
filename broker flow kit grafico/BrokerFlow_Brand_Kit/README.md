# BrokerFlow — Brand Kit

Riferimento visivo approvato per il progetto BrokerFlow.

## Contenuto
- 01_Loghi: versioni primaria, orizzontale, icona, monocromatica e dark in SVG + PNG
- 02_Colori_Font: palette, gradienti, wordmark e indicazioni tipografiche
- 03_Linee_Guida: guida rapida del marchio in PDF
- 04_Originale: tavola grafica approvata usata come riferimento

## Posizionamento visivo
BrokerFlow deve comunicare un prodotto software fintech per il mondo dei mutui: semplice, affidabile, veloce e orientato al controllo del flusso della pratica.
